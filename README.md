# Справка NirCmd на русском языке (CHM)

Полный качественный перевод официальной документации консольной утилиты **NirCmd** от [NirSoft](https://nirsoft.net) на русский язык, скомпилированный в удобный файл справки формата `.chm`.

## 📥 Скачать перевод: https://github.com/alexandershmel/nircmd-ru-help/releases/tag/v0.1

👉 **[Скачать NirCMD](https://www.nirsoft.net/utils/nircmd.html)**

## ⚠️ Как правильно открыть CHM-файл в Windows

По умолчанию Windows блокирует содержимое справочных файлов, скачанных из интернета (вместо текста отображается пустая страница или ошибка навигации). Чтобы снять блокировку:

1. Распакуйте архив `NirCMD.zip` в любую удобную папку.
2. Нажмите правой кнопкой мыши на распакованный `.chm`-файл и выберите **Свойства**.
3. В самом низу окна поставьте галочку **Разблокировать** (Unblock).
4. Нажмите **Применить** и **ОК**, после чего файл откроется корректно.
